# Wunabuy Mobile App

React Native mobile application for Wunabuy — supports three user roles:
- **Buyer** — search, buy, track delivery, chat, watch videos (Phase 2)
- **Seller** — manage products, orders, chat, post videos (Phase 2)
- **Transport Provider** — accept delivery jobs, navigate, earn

## Setup

```bash
npm install
cp .env.example .env  # Fill in values
npx expo start
```
