# Wunabuy Staff Portal

Internal web application for Wunabuy company staff. Six department dashboards:
- Accounting/Finance
- IT/Engineering
- Customer Service
- Operations
- Compliance/Legal
- Marketing

## Setup

```bash
npm install
cp .env.example .env  # Fill in values
npm run dev
```
